# MALFUNCTIONING

这是一个GDI图形特效恶搞程序(分类为trojan.msil/exnet)
本程序包含安全和危险模式

## ⚠警告⚠
- 请勿利用此程序破坏计算机
- 若执行本程序所引发的一切后果需运行者自行承担
- 程序仅供娱乐教育，无恶意目的
## 运行方法：
MALFUNCTIONING.EXE <参数>
参数(不区分大小写)：
- `/help`显示帮助，并退出程序
- `/bypasswarning`绕过警告
- `s:n`设置每个特效时长为n秒(0<n≤100)
- `it:n`发作前延时的时间设为n(n>0)
- `enableunsafemode`启用危险模式
默认参数：
s:20 it:5

## 非危险模式
- 在无`enableunsafemode`参数下，程序默认启动安全模式
- 程序并不会造成永久性破坏，运行完成后重启系统最佳
## 危险模式
- 在包含`enableunsafemode`参数，程序启动危险模式，此模式不安全
- 程序会疯狂移动窗口、鼠标
- 程序会创建100个文件到回收站
- 程序将会标记自己为系统关键进程，所以**千万不能使用任务管理器结束进程**
